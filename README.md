\# X-SCRM

\### Explainable Supply Chain Risk Management



X-SCRM is an AI-assisted third-party cybersecurity risk assessment platform designed to help organisations identify, evaluate and prioritise risks associated with external vendors and suppliers.



The project combines rule-based risk scoring, machine learning and an interactive dashboard to make vendor risk assessments more structured, consistent and explainable.



The project explores how data science and explainable AI can support Third-Party Risk Management (TPRM), Governance, Risk and Compliance (GRC), and cybersecurity decision-making.



\---



\## Project Objectives



\- Assess cybersecurity risks associated with third-party vendors.

\- Evaluate vendors across multiple risk dimensions.

\- Categorise vendors into Low, Medium and High risk tiers.

\- Apply machine learning to identify patterns in vendor risk profiles.

\- Improve risk transparency through explainable scoring.

\- Provide an interactive dashboard for exploring vendor risk assessments.



\## Current Features



\### 1. Synthetic Vendor Dataset



The project includes a synthetic dataset containing 10,000 vendor records.



The dataset contains vendor attributes such as:



\- Industry and geographical region.

\- Vendor criticality.

\- Data sensitivity.

\- API access level.

\- Incident history and severity.

\- Other cybersecurity and business risk indicators.



Synthetic data is used to support development, experimentation and reproducibility without exposing real organisational or vendor information.



\### 2. Rule-Based Risk Engine



The rule-based engine evaluates vendors across four risk categories:



| Risk Category | Maximum Score |

|---|---:|

| Cybersecurity | 40 |

| Compliance | 30 |

| Business Criticality | 20 |

| Incident History | 10 |

| \*\*Total\*\* | \*\*100\*\* |



Vendors are assigned risk tiers based on their overall scores:



| Risk Score | Risk Tier |

|---|---|

| Below 40 | Low |

| 40–69 | Medium |

| 70–100 | High |



The scoring engine also provides component-level risk contributions to help explain how individual factors influence the overall assessment.



\### 3. Machine Learning Risk Classification



X-SCRM incorporates a Random Forest classification model to learn patterns from vendor risk profiles.



The machine learning pipeline includes:



\- Data preprocessing.

\- Categorical feature encoding.

\- Class imbalance handling.

\- Model training and evaluation.

\- Risk classification.

\- Validation-based threshold tuning.



The dataset contains an imbalanced distribution of risk tiers, particularly for High-risk vendors. The project therefore explores techniques to improve the identification of higher-risk vendors.



\*\*Important:\*\* The current model learns from risk tiers generated by the rule-based engine. It does not predict actual security breaches or independently validated real-world vendor incidents. Its outputs should be treated as decision-support recommendations rather than definitive risk assessments.



\### 4. Interactive Dashboard



The Streamlit dashboard provides an interface for exploring vendor risk assessments.



Current functionality includes:



\- Vendor risk distribution.

\- Risk-tier filtering.

\- Individual vendor selection.

\- Overall risk scores.

\- Risk component breakdowns.

\- Vendor-level assessment details.

\## Installation and Setup



\### Prerequisites



\- Python 3.10 or later.

\- Git.

\- A code editor such as Visual Studio Code.



\### 1. Clone the repository



```bash

git clone https://github.com/Tshepo97-codE/x-scrm.git

```



\### 2. Navigate into the project



```bash

cd x-scrm

```



\### 3. Create a virtual environment



```bash

python -m venv venv

```



\### 4. Activate the environment



Windows CMD:



```cmd

venv\\Scripts\\activate

```



Windows PowerShell:



```powershell

.\\venv\\Scripts\\Activate.ps1

```



\### 5. Install dependencies



```bash

pip install -r requirements.txt

```



\### 6. Launch the dashboard



```bash

streamlit run dashboard/app.py

```



The dashboard should open in your browser.

\## Project Limitations



X-SCRM is an ongoing development project.



Current limitations include:



\- The dataset is synthetic and does not represent actual vendor populations.

\- Machine learning labels originate from the rule-based scoring engine.

\- Model performance on synthetic data does not establish real-world predictive performance.

\- High-risk classification requires careful evaluation because of class imbalance.

\- Model recommendations require human review before being used in operational decisions.

\- Some planned modules, including explainability and model management components, are not yet implemented.



These limitations are important when interpreting model performance and evaluating the platform's suitability for real-world environments.
